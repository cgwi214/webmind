电商后台设计说明

- 商品列表页：搜索区（商品名称输入框 + 查询/重置）；表格列为 商品名称、商品编码、分类、价格、库存、上架状态、创建时间；右上"新增商品""导出"按钮；行内"编辑""删除"；底部分页。
- 商品编辑表单页：分组表单（基础信息 / 价格库存 / 图文描述）；字段 商品名称、商品编码、分类、价格、库存、上架状态、商品描述；商品描述支持图片上传；底部"提交""重置"。
- 订单列表页：搜索区（订单号）；表格列为 订单号、下单用户、订单金额、支付状态、下单时间；右上"导出"；底部分页。
- 数据看板页：顶部 3 个指标卡（今日订单数、今日销售额、新增用户数）；下方趋势图占位；右上"查询"时间范围。
- 通用：左侧导航 + 顶部面包屑；主色 #409EFF。
